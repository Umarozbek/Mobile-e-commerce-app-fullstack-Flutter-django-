# Mart

Flutter ilovasi — **millionhalal.uz** e-commerce platformasi uchun mobil ilova (Android / iOS).

## Tezkor boshlash

```bash
flutter pub get
flutter run
```

## Batafsil dokumentatsiya

Loyiha arxitekturasi, sozlash, state management, API, feature modullari va konvensiyalar haqida to‘liq qo‘llanma:

- **[docs/DOCUMENTATION.md](docs/DOCUMENTATION.md)** — batafsil Flutter loyiha dokumentatsiyasi

Hujjatda quyidagilar yoritilgan:

- Talablar va sozlash (Flutter, Firebase)
- Clean Architecture va papka tuzilishi
- BLoC/Cubit state management
- GetIt dependency injection
- Tarmoq qatlami (Dio, ApiClient)
- Barcha feature modullari (auth, home, cart, orders, …)
- Ko‘p tillilik (uz, ru, en, ko)
- Tema va dizayn tizimi
- Firebase (FCM, Analytics)
- Yangi feature qo‘shish bo‘yicha qadamlari
- Build va reliz

## Texnologiyalar

- Flutter 3.x, Dart 3.x
- BLoC / Cubit (flutter_bloc)
- GetIt, Dio
- easy_localization, Firebase (FCM, Analytics)
- GetStorage, Drift, flutter_secure_storage
